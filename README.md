# GestureSpeak

Локальный прототип распознавания дактильных букв русского жестового языка. Браузер показывает видео и ключевые точки кисти. Удержание распознанной буквы добавляет её в редактируемый текст, который можно озвучить по-русски.

## Запуск на Windows

1. Откройте **`Start.cmd`**. Для установки нужен 64-битный Python 3.12. При первом запуске программа устанавливает пакеты в `.venv` и скачивает модели MediaPipe и голоса Piper. После установки интернет для работы приложения не требуется.
2. Откроется браузер на `http://127.0.0.1:8765/`. Нажмите **«Включить камеру»** и разрешите доступ к ней. Для готовой записи выберите **«Открыть видео»**. Кнопка **«Демо»** распознаёт буквы из записей Bukva и набирает **ПРИВЕТ**.
3. Покажите одну кисть, удерживайте жест примерно полсекунды. Для повторной буквы ненадолго уберите руку. Нажмите букву в подсказках, чтобы посмотреть её исполнение. Для ручного подтверждения выключите «Автоввод».
4. Отредактируйте фразу и нажмите **«Озвучить текст»**.

GestureSpeak поддерживает 20 букв **А Б В Г Д Е Ж И К М О П Р С Т У Ф Х Ш Я**. По буквам можно набрать «ПРИВЕТ», «СПАСИБО» и «ПОКА». Модель распознаёт положение кисти. Для Д она реагирует на характерное положение кисти, а движение знака в расчёт не входит.

В русском жестовом языке есть отдельные жесты для целых слов, в том числе для «привет». Дактильная азбука пригодится, когда нужно передать написание имени, названия или термина. GestureSpeak работает в режиме дактильного ввода. [Дактильная азбука Bukva](https://aclanthology.org/2026.wslp-1.15/) · [Словарные жесты Slovo](https://github.com/hukenovs/slovo)

### Камера смартфона

Камеру телефона, подключённую как веб-камеру Windows, можно использовать в обычном режиме, выбрав её в списке камер приложения. Интерфейс также адаптируется под телефон и может открыть его камеру напрямую, когда Python-сервер запущен на ноутбуке в той же доверенной сети и телефон доверяет HTTPS-сертификату с IP ноутбука в SAN.

```powershell
.\.venv\Scripts\python.exe app.py --lan-address 192.168.1.20 --cert cert.pem --key key.pem
```

Подставьте адрес своего ноутбука и откройте `https://<адрес>:8765/` на телефоне. Доступ через LAN открывается только при явном запуске с этими параметрами. Windows может попросить разрешить входящие соединения для частной сети.

## Как работает распознавание

1. Браузер отправляет JPEG-кадр размером до 640 px по длинной стороне. OpenCV декодирует его и передаёт в MediaPipe Hand Landmarker, который выделяет 21 точку одной руки.
2. Координаты приводятся к центру запястья, общему масштабу и правой руке. К 63 координатам добавляются 210 попарных расстояний.
3. Классификатор `273 → 192 → 96 → 21` обучен в PyTorch. Последний класс объединяет примеры букв за пределами словаря. При запуске те же float32-слои вычисляются в NumPy, поэтому для работы камеры PyTorch устанавливать не нужно.
4. Браузер требует последовательные наблюдения с достаточной уверенностью. Фильтр удержания и паузы между вводами подавляет дрожание и дубли. Piper синтезирует речь из готовой фразы, а браузер воспроизводит WAV.

По умолчанию сервер слушает только `127.0.0.1`. Кадры и фразы обрабатываются в памяти. Браузер открывает выбранный видеофайл на устройстве и отправляет на распознавание отдельные кадры. Камера запрашивается после нажатия кнопки, микрофон не используется.

## Модель, данные и проверка

Из 1728 пригодных роликов Bukva 1030 использованы для обучения, 270 для валидации и 428 для теста. В тесте участвовали 20 человек, чьи записи исключены из обучения и валидации. Модель усредняет вероятности по кадрам отдельного ролика. Порог 0,55 выбран на валидации. Эти метрики относятся к изолированным жестам из датасета.

| Проверка | Результат |
|---|---:|
| Первая догадка на поддерживаемых буквах | 311 / 376 (82,7%) |
| Первая догадка на новых буквах Б В Г Е Ж У Ф Х Ш Я | 162 / 187 (86,6%) |
| Правильно принято после порога | 275 / 376 |
| Ошибочно принято после порога | 8 / 376 |
| Не принято после порога | 93 / 376 |
| Принято среди букв вне словаря | 12 / 52 |

[Полные метрики по каждой букве](assets/metrics.json).

Работу непрерывного ввода дополнительно проверяет деморолик и тест временного фильтра. Вторая команда требует Node.js 22.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node --test tests/letter-gate.test.mjs
```

Для переобучения поставьте `requirements-train.txt`, затем запустите `collect.py --save-test-videos` и `train.py`. Скрипт `collect.py` загружает диапазоны ZIP-архива Bukva для выбранных клипов. Исходные видеоролики остаются в локальном `.cache` только при сохранении тестовых примеров. `make_demo.py` пересобирает подсказки и демовидео, для этого нужен FFmpeg.
